### 2.2 最小查询契约

| 需要证明的事实 | 补丁与调用端要求 |
| --- | --- |
| 原服务与目标 | 请求绑定准确 conversation/thread 和已核验 owner；处理端核验自己仍为 owner。响应带原生 thread/cwd 与实际状态，不能只回显客户端输入充当身份。owner/连接代际变化使旧响应失效。 |

| 状态含义 | 仅经验证的 `idle` 可作为空闲观察；`active` 等待，`notLoaded`/owner 不可达等待连接，`systemError`、字段缺失或冲突保持未知。`resumed` 单独不能放行。 |
