## 6. 失败、检查及限制

- 精确 Python 解释器的标准库与既有 IPC 模块导入预检通过，模块 SHA-256 与上轮 CRLF 版本一致，预检未开连接。
- 安装核验脚本第一遍在签名子进程阶段非零退出，stderr UTF-8 解码也失败；完整底层 PowerShell 原因没有从该次输出恢复。改为显式加载签名模块并设置 UTF-8 后通过。该失败保留在本地；没有归因为网络故障或服务入口失败。
- 总共两次元数据管道连接，均已关闭；两次都没有协议读取、协议写入、初始化或状态请求。归档完整哈希仅在成功检查中执行一次。
- 成功核验的安装归档、源码、签名与进程/TCP 元数据支持本报告限定结论。源码搜索部分输出曾截断，所引用关键片段随后单独读取；不声称阅读全部安装包或完整历史。
- 本次没有运行 185 项历史运行套件；生产行为未改，不用文档检查冒充运行回归。未验收 GUI、调度、模型投递、窗口链、业务交付、原服务摘要状态或跨版本兼容。
