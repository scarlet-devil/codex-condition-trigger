## 设置继承与 Hook 边界

发送请求只携带原 conversation、稳定 client-message ID 和文本，`inheritThreadSettings=true`，`isSteering=false`。未发送模型、cwd、审批或沙箱覆盖。发送前保存的设置与实际新回合 turn_context 逐字段相等：model=`gpt-6.1-sol`、effort=`ultra`、approval=`on-request`；cwd与sandbox_policy整体也相同，私有路径不公开。

同一原生回合中实际出现 UserPromptSubmit 记录，session/turn 与接受回执一致；目标回合收到 developer 连续性提示，并用工具读取对应 Hook 结果和来源。目标保留暂停项，未做 source ACK，也未把只读小试扩成业务工作。本轮只证明**这一次 IPC 回合的 Hook 提示可达且被响应**，不计作既有自然样本预算中的常规片段，不声称去重、恢复收益或整体 Hook 实验通过。发起窗口只维护自己的续接记录，没有替另一窗口 ACK。
